# ADR 0003: LLM provider abstraction and source checking

**Context:** Users should be able to use search without an external API key, and switch between cloud and compatible local endpoints.

**Alternatives:** Hard-code one hosted provider; use an OpenAI-compatible adapter behind a provider interface; build against an agent framework.

**Decision:** Use an explicit OpenAI-compatible adapter behind a small interface, and require an affirmative request flag before sending excerpts and history to the configured provider. Check returned citation IDs against the supplied context.

**Rationale:** This keeps retrieval independent of generation, permits local compatible servers, and makes the data transfer visible to the user.

**Trade-offs:** Not every compatible server implements identical response formats. Citation membership only confirms that an ID was in the supplied context; it does not prove that a claim is supported or solve prompt injection. Real provider calls remain opt-in and have not been verified in this environment.
